# Dawnmere 0.1.12

Update with `dawnmere update`, or run the install line again. This release updates the engine to 0.1.10; the CLI, the plugin and the connector are unchanged apart from their version.

- **"Forget that" said in conversation reaches saved memories.** Before, it erased the short facts about the subject, and a saved memory saying the same thing stayed and went on being put into prompts. Now such memories are hidden from every app at once, ten a day at most. You see one line naming them by number (on the start screen in the Claude Code terminal, with your message elsewhere): `dawnmere forget N` deletes one for good now, `dawnmere restore N` brings it back. Otherwise each is deleted 30 days after you were told, and never if you were not. An AI app's shell can neither delete nor restore them. The background model decides which memories say the same thing, so it can miss one, or hide one that mentions the subject only in passing.
- **Two imports at once** no longer fail with "No such file or directory".
