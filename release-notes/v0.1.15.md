# Dawnmere 0.1.15

Update with `dawnmere update`, or run the install line again. This release updates the engine to 0.1.13; the CLI, the plugin and the connector are unchanged apart from their version.

- **One `restore` now undoes a whole forget by an app.** Before, `dawnmere restore N` brought back only memory N, and the copies, the Claude Code file copy and the facts hidden with it were still deleted a day later. Now restoring any memory an app's forget hid brings them all back. Your own forget still cannot be undone, and a restore never undoes a different forget.
