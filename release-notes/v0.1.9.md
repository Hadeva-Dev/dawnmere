# Dawnmere 0.1.9

Update with `dawnmere update`, or run the install line again.

- Setup also connects Windsurf, Gemini CLI and VS Code when they are installed. Like Cursor, they see work notes only until you widen them with `dawnmere access`.
- Dawnmere's own model calls no longer follow a provider you set for Claude Code. If Claude Code points at another provider, `dawnmere doctor` and setup say so: background reading needs a Claude login for now, and recall and remember work as before.
- More AI apps are recognised as agents when you widen an app's access, so a widening can't be started from inside them.
