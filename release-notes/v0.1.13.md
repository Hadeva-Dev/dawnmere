# Dawnmere 0.1.13

Update with `dawnmere update`, or run the install line again. This release updates the engine to 0.1.11; the CLI, the plugin and the connector are unchanged apart from their version.

- **Background reading no longer sends pieces of a password, key or card number to your model provider.** It cut a long conversation to fit before masking it, so a credential that a cut fell inside was no longer recognised, and its pieces went out unmasked. Now each credential is found on the whole message before anything is cut, and masked wherever its pieces land; nothing is masked less than before. One cost: a private key's BEGIN line with no END line hides the rest of that message from background reading.
