# Dawnmere 0.1.7

A patch release. Update with `dawnmere update`, or run the install line again.

- Fixes a first setup with existing Claude Code notes skipping the trust question. Setup now counts the notes it imported, asks once whether to trust them as your own (or, with `--yes`, says how to confirm them later), and only warns when nothing could be imported.
- `lflabs-memory held` says "them" when more than one note is waiting.
- With Claude Code's folder present but not its `claude` command, setup's apps row says the hooks are in place and that memory's tools in Claude Code need the `claude` command.

Engine 0.1.5.
