# Dawnmere 0.1.10

Update with `dawnmere update`, or run the install line again.

- **Everything is called Dawnmere now.** The MCP entry in each app's config, the Claude Code plugin and its marketplace were `lflabs-memory` and `lflabs`; they are `dawnmere` now, and the plugin is `dawnmere@dawnmere`. Updating, setup and the install line rename them for you in Claude Code, Codex, Cursor and every other connected app. The entry keeps its settings, its key included, so no app lists memory twice. `dawnmere uninstall` removes either name, and `dawnmere doctor` points out anything still under the old one.
- **Install from Claude Code.** Run `/plugin marketplace add LF-Labs-Inc/dawnmere` and `/plugin install dawnmere@dawnmere`, then `/dawnmere:setup`. It runs the install line (you approve each command), then has you run `dawnmere setup` in Terminal, or runs it with the defaults if you say so. Until it's set up, a new session says so in one line, and the plugin installs nothing by itself.
- **Memory commands under `dawnmere`.** `dawnmere held`, `trust`, `forget`, `restore`, `search` and `add` work like the engine's own commands, dialogs included. Every message now names them this way; `lflabs-memory …` still works.
- **New apps.** Setup also connects Qwen Code, Kimi Code, Qoder CLI, iFlow CLI and Cline CLI when they are installed. Like Cursor, they see work notes only.
- **A new home on GitHub.** Dawnmere now lives at [LF-Labs-Inc/dawnmere](https://github.com/LF-Labs-Inc/dawnmere), and Homebrew's line is `brew install lf-labs-inc/tap/dawnmere`. Setup and updating move Claude Code's plugin to the new address along with the rename. The old addresses redirect.
- **`dawnmere --version`** prints the release, with the engine and connector versions that go with it.

Engine 0.1.8:

- Forgetting a memory also removes its words from the notes handed to the next session, from the chat index when it is on, from AUDIT.md, and from every backup copy.
- Claude Code's own memory file for something you typed is filed with your note. Forgetting either one takes both, and a forgotten file is never imported again. Your Claude Code file itself is left alone.
- Background reading files facts about your team, project, tools or work where every app sees them. Facts about your own life stay personal.
- A scripted `claude -p` run is no longer asked to save a "remember that" with a tool it can't use.
- When an app's forget is cleaned up a day later, or a session that sees only some of your notes forgets something, the clean-up stays within what that app or session may see.
- A fact that mixes your private life with work is filed personal. So are job interviews, leaving a job, pay, reviews, HR matters and relationships.
